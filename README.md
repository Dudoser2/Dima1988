## Описание проекта
Приложение «Movie Library» — это личная кинотека с графическим интерфейсом. Программа позволяет сохранять информацию о просмотренных или желаемых фильмах, включая название, жанр, год выпуска и персональный рейтинг. Приложение умеет сохранять базу данных в файл `movies.json` и поддерживает фильтрацию по жанру и году.

## Инструкция по запуску

### Требования
* Python 3.x или выше.

### Запуск
1. Убедитесь, что у вас установлен Python.
2. Скачайте файл `main.py` в отдельную папку.
3. Откройте терминал/консоль в этой папке и запустите команду:
```bash
python main.py
